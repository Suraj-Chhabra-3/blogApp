# 📝 Blog App

A full-featured blog application built with **React** and **Appwrite**. Users can register, log in, create blogs, upload images, edit and delete their posts, and view all blogs on the platform.

---

## 🚀 Features

- 🔐 User Authentication (Register, Login, Logout)
- 📝 Create, Read, Update, Delete blog posts
- 📸 Image Upload via Appwrite Storage
- 📃 View all blogs from all users
- ✏️ Edit and delete only your own blogs
- 🕶️ Responsive, clean UI built with React

---

## 🛠️ Tech Stack

- **Frontend**: React (Vite)
- **Backend**: Appwrite (Cloud)
- **Database**: Appwrite Collections
- **Auth**: Appwrite Authentication
- **Image Storage**: Appwrite Storage
- **Styling**: Tailwind CSS
